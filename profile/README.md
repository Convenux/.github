<h1 align="center">Convenux</h1>

<p align="center">Every con, every panel, everyone you know.</p>

Convenux follows the anime, comic, gaming, furry, tabletop and sci-fi conventions you go to: dates, venues, guests, schedules and tickets, read from each organiser's own site and kept up to date, with meetups and photos from the people who are there.

- **[convenux.com](https://convenux.com)**: the app for iPhone and Android.
- **[db.convenux.com](https://db.convenux.com)**: the convention database behind it, where every value carries the source it came from and when it was last checked. Anyone can suggest a correction.
- **[Developers](https://db.convenux.com/developers)**: API keys and the [API reference](https://db-api.convenux.com/docs/api).

Our repositories are private. For questions, write to [hello@convenux.com](mailto:hello@convenux.com). To report a vulnerability, see our [security policy](https://github.com/Convenux/.github/blob/main/SECURITY.md).
